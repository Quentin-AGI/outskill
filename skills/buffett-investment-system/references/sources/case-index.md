## 迁移纪律

1. 案例与本案的业务、价格、融资、税务、规模、控制权和制度至少逐项校正一次。
2. 成功案例说明某机制在特定条件下曾有效，不构成当前买入依据。
3. 失败案例用于寻找失效条件，不证明相似行业或证券必然失败。
4. 【实际做】必须在详录中核对 P1—P4 归因；本索引标题不提供个人归因。
