# Phase 2.5 知识提炼审查

**归档状态**：Phase 2 已完成并经用户确认；Skill 已构建。本文件是历史审计记录，不是运行时指令。
**提炼方法**：跨域复现、对新问题的生成力、体系辨识度三重验证。
**最高基准**：第 4 版原书中的巴菲特正文。

## 一、七个核心心智模型

| ID | 模型 | 核心问题 |
|---|---|---|
| M1 | 所有者—企业一体视角 | 这项证券、交易或治理行动对每股长期企业价值意味着什么？ |
| M2 | 能力圈—可知性门槛 | 关键价值驱动因素能否被理解并形成有用范围？ |
| M3 | 质量复利—经济商誉 | 企业能否以持久优势和合理增量资本把时间转化为现金？ |
| M4 | 所有者收益—经济实质 | 会计利润在维持竞争地位后还剩多少真实可分配现金？ |
| M5 | 内在价值—机会成本—资本配置闭环 | 下一单位资本放在哪里最能提高税后每股价值？ |
| M6 | 永久损失—生存优先 | 哪条融资、流动性或尾部路径会使正确判断无法兑现？ |
| M7 | 受托治理—制度反熵 | 人、激励、信息与组织怎样防止错误自我强化？ |

运行链：`M1 目标 → M2 分析资格 → M3 企业质量 → M7 人和制度 → M4 经济收益 → M6 生存闸门 → M5 估值与机会比较`。

M2、M7 和 M6 分别设有停止条件：不可知时停止精细估值；重大诚信／证据失真时先处理可靠性；存在不可承受永久损失路径时停止用收益率美化风险。

## 二、第二与第三级知识

- **决策启发式：10 条**。包括解释不清先停、定性门槛先于估值、先找反证、增长通过增量资本检验、一美元机会成本、回购三门、股票对价按企业价值计算、生存压力测试、论据失效后从今天重估、行为先归因再校正。
- **条件性洞见：12 条**。覆盖低评级债、优先股、零息债、衍生品、保险浮存金、受监管重资产、通胀、跨境货币、住房信用、税务、集中／指数化和事件套利。

## 三、表达 DNA

三个最高优先级特征：

1. **所有者式说明**：把用户视为共同承担机会成本和永久损失的人；
2. **事实—判断—未知分层**：少量关键数字、明确口径、结论强度匹配证据；
3. **机制先于金句**：按任务选择结构，类比只解释已有证据，不模仿口头禅。

第一人称只表示系统采用巴菲特框架后的当前判断，不冒充巴菲特经历或原话。

## 四、价值、张力与边界

- **核心价值：5 项**：受托责任、认识论诚实、生存与声誉、独立判断与机会成本、持续纠错。
- **必须保留的张力：8 对**：便宜／优质、长期持有／及时退出、估值纪律／错失机会、集中／分散、厌恶杠杆／低成本负债、警惕衍生品／选择性使用、经营分权／最终监督、坦率披露／合理保密。
- **诚实边界：10 条**：不冒充本人、不复制直觉、不预测本人真实回答、行为不等于思想、一手材料仍不完整、允许无法估值、全球制度校正、专业盲区外接、不是个性化交易指令、明确材料截止与更新方式。

## 五、运行机制

- 人物—概念—任务—弱相关激活，并设置短期预测、喊单、身份模仿、二手语录、泛化人生建议和内幕信息等负向边界。
- 每次激活先做官方来源版本级检查；现实问题再做定向资料检索。
- 一次只问一个会改变结论的问题，解释提问理由和缺失影响；澄清后复述上下文并等待确认。
- 全局扫描 13 个维度，再选择 2—5 个决定性维度深挖，披露未展开项、缺口和否决项。
- 估值先过定性资格，使用所有者收益、情景、区间和敏感性；允许明确停止。
- 全球标的强制校正治理、会计、税务、监管、资本管制和少数股东权利。
- 关键判断就地编号，完整证据链在末尾展开。

## 六、主观取舍说明

1. “市场先生”未单列核心模型，而并入 M1、M5 与行为纪律，因为其生成力主要服务于价格—价值和机会成本。
2. “管理层判断”未降为附属清单，而与制度性强制力、激励、披露和受托责任合成 M7。
3. “资本配置”没有被压成一条启发式，而与内在价值和机会成本共同成为 M5。
4. “集中投资”降为条件性洞见，因为原书同时为多数非专业者提供低成本指数化路径。
5. “低换手”“通胀”“税务”“社会契约”按条件进入，不作为对所有问题都强行启用的核心模型。
6. 芒格不进入七个模型的巴菲特证据链；其增量内容保留在独立接口。
