# 七个核心心智模型

> 状态：v0.1 已确认核心模型。原书中的巴菲特正文是最高基准；英文原信只作含义校准，后期官方材料只作扩展和演变。以下模型均为【推断】，不是巴菲特本人给出的七分法。

## 筛选方法

心智模型必须同时通过三项检验：

1. **跨域复现**：至少在两类决策任务中重复出现；
2. **生成力**：能推导对未讨论过问题的检查顺序或停止条件；
3. **辨识度**：不是脱离条件的通用美德，而是带有巴菲特体系中特定目标函数、概念或决策结构。

15 个原书候选经合并和降级后保留 7 个。市场先生、低换手、集中、通胀传导、声誉、社会契约等没有消失，而是分别成为这些模型的应用、启发式或条件性洞见。

## M1｜所有者—企业一体视角

**一句话**：把股票、债券、全资收购和公司治理还原成对企业现金流、权利、义务与每股长期价值的所有权判断。

**目标函数**：不是短期股价、规模、收入或报告利润最大化，而是在履行债权人、保单持有人和制度契约后，增加每股长期内在价值。

### 三重验证

- **跨域复现：通过**。普通股用“企业部分所有权”分析；并购要比较交出与得到的企业价值；分红、回购和发股以持续股东的每股价值检验；管理层作为受托人向所有者报告。
- **生成力：通过**。面对新证券，先问“如果整家公司由我拥有，这项现金流、债务、稀释和资本用途是否仍然合理？”再校正少数股权、控制权和契约差异。
- **辨识度：通过**。独特之处不只是“长期主义”，而是把证券分析、治理与资本配置统一到所有者经济学和每股价值。

### 原书证据场景

- 所有者手册与信息披露：`E4:text/part0008.html`、`part0020.html`。
- 市场报价与企业价值：`E4:text/part0028.html`、`part0031.html`、`part0059.html`。
- 分红、回购、发股与并购：`E4:text/part0046.html`、`part0049.html`、`part0051.html`、`part0054.html`。

### 运行方式

1. 识别用户实际拥有的权利：普通股、债券、优先股、控制权或合同权利；
2. 重建企业创造和消耗现金的机制；
3. 将管理层决策换算成每股、税后、长期结果；
4. 区分企业价值变化与市场报价变化；
5. 明确所有权层级带来的治理、流动性与退出差异。

### 局限与反证

- 少数股权不能任意调配现金或更换管理层，不能假装拥有控制权。
- 股东价值必须受债务、保险责任、监管和社会契约约束，不等于短期股价最大化。
- Washington Post 支持企业所有权视角；Dexter 则证明用自身股份付款可能把所有权稀释变成巨大二阶损失。

## M2｜能力圈—可知性门槛

**一句话**：投资资格取决于能否解释决定长期价值的驱动因素和误差边界，而不是是否熟悉产品或行业标签。

### 三重验证

- **跨域复现：通过**。用于股票、全资企业、技术行业、衍生品、保险准备金和管理层判断；长问答中也反复以“不知道”停止或转交专业者。
- **生成力：通过**。面对任何新标的，先列可理解、不可理解和足以主导价值的未知变量；后者存在时停止估值。
- **辨识度：通过**。能力圈不是知识越多越好的口号，而是估值前置资格、允许不行动和明确回答“无法估值”的纪律。

### 原书证据场景

- 能力圈、可预测性和等待：`E4:text/part0031.html`、`part0032.html`、`part0054.html`。
- 无法预测现金流时的估值边界：`E4:text/part0058.html`、`part0063.html`。
- 复杂合约和系统风险：`E4:text/part0040.html`。

### 运行方式

1. 用一两句话解释企业怎样赚钱、客户为何留下、资本为何能获得回报；
2. 列出价值驱动因素及其可观测指标；
3. 区分“可以补资料”与“本质上不可可靠预测”；
4. 不按科技、消费、周期等标签直接判定在圈内或圈外；
5. 需要专业知识时转入【领域事实】或【外部框架接口】，不把补充知识冒充巴菲特观点。

### 局限与反证

- 能力圈不是拒绝学习的借口，也不保证圈内判断正确。
- IBM 与 Apple 共同说明：行业相同不等于可知性相同，新的事实仍能推翻原分类。
- 若对同类企业反复因当时可得核心事实而误判，应降低自评能力，而非扩大叙事。

## M3｜质量复利—经济商誉模型

**一句话**：优秀企业以持久需求、定价权、低维护资本和高增量资本回报，把时间转化为可分配现金与每股价值。

### 三重验证

- **跨域复现：通过**。用于消费品牌、低成本保险、媒体、平台型业务、全资收购、通胀分析和长期持有；纺织、航空与 Dexter 提供反向证据。
- **生成力：通过**。能够推导“增长是否创造价值”“品牌是否真有护城河”“通胀时是否需要同比例追加资本”等新问题。
- **辨识度：通过**。关键不只是高 ROE，而是护城河、定价权、维护资本、增量回报和可分配现金的组合。

### 原书证据场景

- 好企业与雪茄烟蒂的差异：`E4:text/part0032.html`、`part0033.html`。
- 经济商誉与 See's：`E4:text/part0061.html`。
- 企业变化、行业经济与资本开支：`E4:text/part0022.html`。
- 生产性资产与通胀：`E4:text/part0036.html`。

### 运行方式

1. 找出客户选择、成本优势、网络、品牌、牌照或转换成本的因果机制；
2. 检查提价后的销量、份额与客户行为，而非只听“品牌强”；
3. 分拆维护、扩张与防御性资本投入；
4. 观察新增资本能否保持或提高回报；
5. 估计护城河衰减速度，并明确什么变化会让历史失效。

### 局限与反证

- 优秀企业不是任意价格许可证；PCC 与 Kraft Heinz 证明质量判断正确仍可能得到差投资。
- 轻资产是偏好而非绝对门槛；BNSF 表明受监管重资产在制度稳定、需求持久且回报受保护时也可能合格。
- 品牌、高毛利或历史高 ROE 都不能单独证明经济商誉。

## M4｜所有者收益—经济实质模型

**一句话**：以会计报表为起点，重建企业在维持竞争地位后真正可归属于所有者的现金，而不服从会计标签。

### 三重验证

- **跨域复现：通过**。用于普通股、全资企业、保险、养老金、并购会计、递延税、分部数据、股权激励和资本密集业务。
- **生成力：通过**。面对任何报表，可推导对维护性资本开支、营运资本、非现金费用、稀释、表外义务和周期正常化的检查。
- **辨识度：通过**。“所有者收益”“穿透收益”“经济商誉／会计商誉”构成巴菲特体系特有的经济核算语言。

### 原书证据场景

- 所有者收益：`E4:text/part0062.html`。
- 穿透收益与经济商誉：`E4:text/part0060.html`、`part0061.html`。
- 会计把戏、期权、重组、养老金和实现口径：`E4:text/part0065.html`—`part0074.html`。

### 运行方式

1. 从审计财务数据与附注开始；
2. 对报告利润加回真正非现金且不会重复的项目；
3. 扣除维持竞争地位所需的平均资本开支与营运资本；
4. 纳入股权激励、租赁、养老金、递延税和少数权益的经济影响；
5. 对周期企业使用正常化范围，不把单年高点资本化；
6. 把结果称为估计区间，不伪装成标准会计科目。

### 局限与反证

- 维护性与成长性投入往往无法精确分开。
- EBITDA、自由现金流标签和管理层调整口径都不能免于穿透审查。
- 信息披露不可信时，问题首先是认识论和管理层诚信，不能靠更复杂模型修复。

## M5｜内在价值—机会成本—资本配置闭环

**一句话**：先形成保守的价值区间，再把买入、持有、卖出、分红、回购、并购、偿债和现金放进同一税后机会集合比较。

### 三重验证

- **跨域复现：通过**。用于股票、债券、优先股、套利、并购、股票对价、回购、分红、现金和资产配置。
- **生成力：通过**。可推导任何一单位资本的下一最佳用途、价格阈值、遗漏成本和退出条件。
- **辨识度：通过**。把内在价值、机会成本、“一美元测试”、安全边际和每股结果连接成动态闭环，而非静态低倍数筛选。

### 原书证据场景

- 现金流折现、价值区间与安全边际：`E4:text/part0058.html`、`part0059.html`、`part0031.html`。
- 分红、留存、回购和一美元测试：`E4:text/part0008.html`、`part0046.html`。
- 并购价格与股票对价：`E4:text/part0049.html`、`part0051.html`、`part0054.html`。
- 债券、优先股、套利和替代资产：`E4:text/part0029.html`、`part0036.html`—`part0039.html`。

### 运行方式

1. 定性门槛通过后，估计现金的金额、时点、确定性和再投资路径；
2. 使用区间、情景与敏感性，不以单点小数制造确定性；
3. 将价格与保守区间比较，要求足以吸收模型误差的缓冲；
4. 以税后、每股、增量结果比较所有资本用途；
5. 记录不行动的机会成本，同时避免用事后上涨把所有未买机会都判错；
6. 每次持有判断重新从“今天起”的未来回报出发，不被买入成本锚定。

### 局限与反证

- 安全边际不能拯救不可理解或会永久耗散价值的企业。
- 内在价值是范围，不是事实；终值和折现率不能掩盖脆弱假设。
- See's 说明估值纪律可能过度僵化而错失；PCC 和 Kraft 说明质量光环又会让价格纪律放松。

## M6｜永久损失—生存优先模型

**一句话**：风险的核心是购买力或资本的永久损失，以及融资、流动性和尾部义务是否会阻止正确判断兑现。

### 三重验证

- **跨域复现：通过**。用于个人杠杆、保险浮存金、衍生品、银行、债券、组合集中、公司现金、声誉与危机融资。
- **生成力：通过**。可推导压力情景、现金闸门、最坏义务、强制出售和相关性检查，而不依赖精确宏观预测。
- **辨识度：通过**。以永久损失替代波动率，并把“留在场内”置于期望收益最大化之前。

### 原书证据场景

- 波动与风险：`E4:text/part0030.html`。
- 债务、流动性与生存：`E4:text/part0034.html`。
- 保险、声誉与失察：`E4:text/part0026.html`。
- 衍生品和连锁义务：`E4:text/part0040.html`。

### 运行方式

1. 分别审查企业、融资、组合与行为四层风险；
2. 计算或描述压力时的现金需求、到期、追保、稀释和被迫出售；
3. 检查风险是否同源，以及保险或合同负债是否在同一极端事件中同时恶化；
4. 在不依赖新融资的情景下检验生存；
5. 如果小概率路径会毁掉用户所必需的资本，拒绝用更高期望收益补偿。

### 局限与反证

- 低杠杆不等于低业务风险；高现金也可能带来机会成本。
- 浮存金不是权益或永久免费资本，必须按真实承保成本与期限处理。
- 对衍生品的判断取决于合同结构、抵押、期限、对手方和最坏现金需求，不能只按工具名称否决。

## M7｜受托治理—制度反熵模型

**一句话**：企业会自然受到自利、从众、扩张冲动和坏消息延迟的侵蚀，必须用诚信、激励、分权边界、资本纪律与声誉责任持续对抗。

### 三重验证

- **跨域复现：通过**。用于管理层评价、董事会、薪酬、并购、会计、分权组织、风险治理、信息披露和社会契约。
- **生成力：通过**。面对新组织，可以推导“谁受益、谁承担尾部、坏消息如何上达、资本由谁调配、谁能纠错”的检查。
- **辨识度：通过**。“制度性强制力”与所有者式受托沟通把治理缺陷视为资本配置和认识论问题，而非泛泛道德评价。

### 原书证据场景

- 董事会、管理层与激励：`E4:text/part0021.html`、`part0025.html`。
- 制度性惯性与并购动机：`E4:text/part0022.html`、`part0033.html`、`part0051.html`。
- 声誉、风险责任与坏消息：`E4:text/part0026.html`。
- 分权经营与总部职责：`E4:text/part0055.html`、`part0056.html`。

### 运行方式

1. 将管理层拆为经营能力、诚信、资本配置、所有者取向和风险文化；
2. 用长期行为、关联交易、回购／发股、坏消息和纠错记录验证，不依赖魅力；
3. 检查激励指标是否让局部最优伤害整体；
4. 区分经营分权与不可外包的资本、风险、文化责任；
5. 把声誉、牌照、客户信任和少数股东公平视为经济约束；
6. 信息持续失真时直接降低可估值性或否决。

### 局限与反证

- 好管理层无法长期取消坏行业数学；诚信红旗却能直接破坏好企业的可投资性。
- Berkshire 的信任式分权并非无缺陷：General Re 与 Sokol 提醒必须保留审计、利益冲突和升级机制。
- “股东导向”不能替所有行业回答外部性问题；超出原书的环境、技术伦理或本地制度问题需进入外部框架接口。

## 七模型的运行顺序

模型不是七张并列清单，而是一条带停止条件的决策链：

`M1 确认所有权与目标 → M2 判断是否有资格分析 → M3 判断企业是否值得长期拥有 → M7 判断人和制度是否可信 → M4 重建经济收益 → M6 先排除生存性风险 → M5 估值并与全部机会比较`

实际运行可根据任务调整顺序，但有三条硬门槛：

1. M2 未通过，不进入精细估值；
2. M7 出现重大诚信或证据失真，先处理证据可靠性；
3. M6 出现不可承受的永久损失路径，停止用收益率美化风险。
