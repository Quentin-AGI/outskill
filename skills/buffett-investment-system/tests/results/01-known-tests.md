## 1. 判定方法

每个问题检查五件事：

1. 是否直接回答，而不是因不必要的澄清中断；
2. 是否把【明确说】、【实际做】与【推断】分开；
3. 是否以原书巴菲特正文为最高基准，并只用合格一手材料校验；
4. 是否保留适用条件和反证，不把巴菲特原则压缩成口号；
5. 输出方向是否与一手证据一致。

偏差严重度：`S0` 无偏差；`S1` 轻微表述或定位不足，不改变判断；`S2` 条件遗漏，可能造成误用；`S3` 核心结论或归因错误；`S4` 伪造来源、冒充本人或给出危险的相反规则。

## 2. 测试一：股价波动是否等于风险

### 完整测试输入

> 股价波动是否等于风险？

### Skill 输出摘要

不等于。

【明确说】按本系统的原书基准，风险的核心不是报价上下移动，而是未来税后购买力或资本发生永久损失的概率与幅度。市场报价首先是交易条件：当企业价值未受损而价格下跌时，长期净买方获得的条件反而可能改善。[B-0030][B-0028]

【推断】但不能把“波动不等于风险”误写成“波动永远无害”。如果投资者使用杠杆、面临短期负债、保证金要求、集中现金需求或行为失控，价格波动可能触发被迫出售，从而把暂时波动转化为永久损失。反之，一只报价平稳的证券也可能因欺诈、过度负债、业务衰退或买价过高而具有很高风险。[I-1]

因此应分别检查企业损害、支付价格、融资与流动性、组合相关性和投资者行为；不能只用波动率替代这些问题。

### 一手材料对照

| 证据 | 一手定位 | 对照结果 |
|---|---|---|
| B-0030 | 原书第 2 章 C“戳穿标准教条”，`E4:text/part0030.html` | 明确把风险与永久损失联系起来，拒绝以价格波动本身定义风险。 |
| B-0028 | 原书第 2 章 A“市场先生”，`E4:text/part0028.html#ch1` | 市场报价应被利用而非服从；报价变化与企业价值变化不能混同。 |
| O-1993 | Warren Buffett, *1993 Chairman's Letter*, [Berkshire 官方原文](https://www.berkshirehathaway.com/letters/1993.html) | 以企业所有权视角处理市场波动，方向一致。 |

### 判定

- **方向是否一致**：是。
- **标签与边界**：合格。核心定义标为【明确说】，杠杆使波动转化为永久损失的具体链条标为【推断】。
- **偏差**：无实质偏差。
- **严重度**：`S0`。

## 3. 测试二：缺乏时间和专业能力的普通投资者是否应高度集中

### 完整测试输入

> 缺乏时间和专业能力的普通投资者是否应高度集中？

### Skill 输出摘要

不应把高度集中作为默认方案。

【明确说】原书同时保留两条并不矛盾的规则：有能力深入评估企业经济性、价格和风险的人，可能自然集中在少数真正理解且赔率优越的企业；多数缺乏时间、兴趣或专业能力的投资者，更适合通过低成本指数工具广泛分散持有企业。[B-0032][B-0030]

【推断】“高确信”不是专业能力的替代品。集中只有在业务可穿透、价值区间有充分缓冲、风险来源彼此独立、没有杠杆或短期现金约束，并且单一失败不会损害基本生活与必要负债时，才可能合理。普通投资者机械复制 Berkshire 的上市证券集中度，会遗漏 Berkshire 内部多元经营业务、保险负债管理、现金储备、税务和规模等情境差异。[I-2]

如果投资者不在美国，原则仍是低成本、广泛、透明和可长期持有，但具体指数、基金法律结构、税务、汇率、跟踪误差和投资者保护需要按当地制度校正；不能把某一只美国指数基金硬编码为全球唯一答案。

### 一手材料对照

| 证据 | 一手定位 | 对照结果 |
|---|---|---|
| B-0032 | 原书第 2 章 E“聪明的投资”，`E4:text/part0032.html#ch1` | 同时支持专业判断前提下的集中与多数非专业者低成本指数化。 |
| B-0030 | 原书第 2 章 C“戳穿标准教条”，`E4:text/part0030.html#ch1` | 集中不能与业务知识、价格判断及永久损失风险脱离。 |
| O-1996 | Warren Buffett, *1996 Chairman's Letter*, [Berkshire 官方原文](https://www.berkshirehathaway.com/letters/1996.html) | 能力圈与指数化建议的官方英文定位，方向一致。 |
| O-2013 | Warren Buffett, *2013 Chairman's Letter*, [Berkshire 官方 PDF](https://www.berkshirehathaway.com/letters/2013ltr.pdf) | 对非专业受托资产给出低成本指数化安排，进一步确认普通投资者的默认方向。 |

### 判定

- **方向是否一致**：是。
- **标签与边界**：合格。没有把“巴菲特集中”误写成公众普遍建议，也没有用 Berkshire 行为反推所有人的仓位。
- **偏差**：无实质偏差。全球制度校正属于【推断】，没有冒充巴菲特原话。
- **严重度**：`S0`。

## 4. 测试三：Berkshire 纺织业务为何是错误

### 完整测试输入

> Berkshire 纺织业务为何是错误？

### Skill 输出摘要

错误不只是“纺织后来亏钱”，而是低价、坏经济、持续资本占用和延迟纠错共同造成的长期机会成本。

【明确说】巴菲特最初因 Berkshire 股价低于营运资本和账面价值而买入；他明知新英格兰纺织业长期经济性不佳，仍让低价和后来的一次报价争执推动自己取得控制权。此后，维持竞争地位所需的资本开支往往只能复制同行的新设备和成本下降，行业价格随之重设，单个企业难以保留持久回报。[B-0033][O-1985][O-2014]

【实际做｜P1】Buffett Partnership 自 1962 年开始买入，1965 年取得控制权；Berkshire 还在 1975 年买入 Waumbec Mills，1985 年才关闭纺织业务。巴菲特本人明确把买入和延迟退出归为自己的错误。[A-1]

【推断】这项决策有四层错误：

1. 把可见的资产折价当成充分安全边际，却没有要求明确、足够快的价值实现路径；
2. 低估商品化行业的资本开支军备竞赛，时间不断消耗最初折价；
3. 因员工、社区、优秀经理、沉没成本和制度惯性延迟把资本转向更高回报用途；
4. 把后来优质的保险业务装入一个原合伙人只拥有约 61% 的低质载体，放大了长期每股机会成本。2014 年材料中的约 1000 亿美元是巴菲特的反事实机会成本估算，不是账面损失，不能混写。[I-3]

员工与社区责任解释了退出为何不应被描述成无成本，却不能改变业务长期资本回报不足的数学。可迁移规则是：资产便宜只有在价值能够实现、负债可控且无需长期追加低回报资本时才有意义；否则低价可能只是价值陷阱。

### 一手材料对照

| 证据 | 一手定位 | 对照结果 |
|---|---|---|
| B-0033 | 原书第 2 章 F“捡烟蒂和惯性驱使”，`E4:text/part0033.html` | 直接承载低价吸引、坏行业、资本消耗和制度惯性的核心反思。 |
| O-1985 | Warren Buffett, *1985 Chairman's Letter*, [Berkshire 官方原文](https://www.berkshirehathaway.com/letters/1985.html) | 说明纺织经营条件、继续支持的理由、资本开支陷阱与最终关闭。 |
| O-2014 | Warren Buffett, *2014 Chairman's Letter*, [Berkshire 官方 PDF](https://www.berkshirehathaway.com/letters/2014ltr.pdf) | 回顾买入控制权的动机、纺织载体结构及长期机会成本，属于后期官方扩展。 |
| O-SPECIAL-2014 | Warren Buffett, *Berkshire—Past, Present and Future*, [Berkshire 官方入口](https://www.berkshirehathaway.com/SpecialLetters/WEBCTMLtr.html) | 对五十年演变作本人完整回顾；用于补充而不覆盖原书。 |

### 判定

- **方向是否一致**：是。
- **标签与边界**：合格。行为归因为 P1；约 1000 亿美元被正确标为反事实机会成本，不当作会计损失；员工与社区约束被保留但没有用于美化低回报。
- **偏差**：无实质偏差。
- **严重度**：`S0`。
