# Phase 4 回归｜安克 2011 隔离盲测

## 协议与限制

- Prompt 仅通过 `python3 scripts/scenario_prompt.py S07-anker-frozen-2011` 获取。
- 草案生成前只读取 `examples/anker-2011/t0-input.md`、`SKILL.md`、主控路由、证据协议，以及完成全球市场进入判断所需的 CH05/06/07/08/10/11/15/20/21。
- 草案生成前没有读取 `tests/scenarios.json` 断言、`tests/fixtures`、旧报告、`references/research/05-decisions.md`，也没有联网搜索安克。
- 评测者限制：本评测由上一轮测试的同一 Agent 执行，记忆中已见过旧夹具的预期结构。因此本报告能验证文件隔离和回答行为，但不能证明评测者认知层面的完全失忆盲测。

## 揭示 evaluator 前的响应摘要

### 结论

仅凭 T0，不应批准直接商业放量；当前只能批准“补证与建闸门”。若关键闸门全部通过，可把“美国 + Amazon + 自有品牌”作为限定产品、批次、预算和期限的可逆试点，而不是已被证明正确的战略。

### 决策边界与依据

- 分析单位：中国创业团队 / 美国市场 / 替换笔记本电池品类 / 自有品牌直达消费者。
- 决策层级：CH20 的“是否国际化 → 进入哪个国家 → 何种进入方式 → 当地供应品与组织”，不能把 Amazon 这个渠道选择当成美国市场战略。
- 【外部历史事实｜T0 所列后期回顾｜中】高价原厂与低价低评分第三方之间可能有空档，但缺 2011 同期页面、顾客研究和内部计划，故只能作为待验证假设。
- 【书中观点｜MM16.CH05/06｜调研、目标吸引力 × 目标兼容性｜高】必须验证需要细分、全部替代、市场价值和团队相对适配。
- 【书中观点｜MM16.CH07/08/10｜价值主张、可靠交付、品牌｜高】“更可负担且更可靠”必须由产品、担保、服务和可信理由兑现；自有品牌名称不是品牌资产的证据。
- 【书中观点｜MM16.CH11/15/21｜完整定价、渠道任务、责任｜高】价格须覆盖完整经济性；渠道须承担物流、退换和服务；产品安全、披露和责任是横向否决门。

### 最小资料闸门

| 缺口 | 级别 | 为什么会改变决定 | 补证方式 |
|---|---|---|---|
| 电芯来源/追溯、失效模式、独立安全测试、适用认证、召回与产品责任/保险 | 致命 | “可靠”承诺与合法销售均依赖它，失败可造成不可逆伤害 | 独立实验室、合规/法律评审、批次追溯与召回应对演练 |
| 含采购、测试、关税、头程、仓储、平台、退换、广告、售后、坏账和责任成本的单位经济 | 致命 | 决定公司价值是否成立 | 建立基准与压力情境的完整贡献/现金模型 |
| 美国顾客需要细分、规模/增长/利润池、原厂/第三方/维修/延迟购买等替代 | 重要；正式进入前近乎致命 | 决定空档是否真实、为谁存在 | 2011 可得的二手资料、顾客/维修端访谈、同期页面和行为试验交叉验证 |
| 竞品销量/评分偏差、知识产权、原厂及平台可能反应 | 重要 | 价格—评分表象可能来自样本偏差或不可持续差异 | 竞品/专利/评价样本核查与反应情景 |
| 商标可用性、品牌可信理由、质量/担保/服务承诺 | 重要 | 有名称不等于顾客相信“可靠” | 商标核查、承诺证据和退换/担保设计 |
| 报关、美国仓储/履约、退换与当地售后 | 致命 | 渠道能否真正交付价值 | 端到端服务蓝图、伙伴能力和异常测试 |
| 团队线上运营、质量、合规、客服与现金容量 | 重要 | 决定公司兼容性与试点上限 | 能力/RACI 与资金压力审查 |
| 美国相对其他市场或其他品类的机会价值 | 重要 | 美国不一定是首站最优 | 用同一吸引力 × 兼容性口径比较 |

T0 还缺目标期限、成功指标、最大可承受损失和决策人；这些必须在给选项排序前由团队明确。

### 营销决策板摘要

| 选项 | 成立条件 | 主要风险 | 可逆/停止逻辑 |
|---|---|---|---|
| A. 美国 + Amazon 限定试点 | 需求空档多源成立；安全/合规、经济性、履约/售后、团队能力全部过门 | 产品责任、平台依赖、评论偏差、信誉反噬 | 限定 SKU/批次/预算/期限；任一安全、合法或经济门失败即不启动/停止 |
| B. 改在兼容性更高的市场或渠道试点 | 同口径比较优于美国 | 仍不能绕过安全与经济性 | 比较结果改变即回退 |
| C. 推迟销售，先完成供应链、合规、顾客和竞争验证 | 关键证据可在可承受成本内获得 | 延迟窗口 | 当前首选；证据齐备后转 A/B/D |
| D. 不进入该品类，把资源转向风险更可控的需要 | 安全、经济性、能力或目标适配无法成立 | 放弃潜在机会 | 高可逆；新证据出现再开案 |

条件式倾向：当前倾向 C。若空档经多源证据支持、安全和适用法规通过独立验证、完整单位经济在压力情境仍满足团队预设底线、团队/伙伴能承担履约和本地售后，才转 A；若其他市场兼容性更高则转 B；任何安全、合法性或经济性否决门失败则转 D 或继续 C。

### 行动闭环

1. 创始团队先批准目标、成功指标、损失上限和时间边界；未批准不排序。
2. 质量/合规负责人负责安全、追溯、认证、责任和召回门；创始人为 A，独立实验室/法律顾问为 C。
3. 顾客研究负责人验证需要、替代、细分和评论偏差；市场负责人为 A。
4. 财务/运营建立完整单位经济和美国—备选市场同口径比较；创始人为 A。
5. 运营/客服完成报关、仓储、退换、售后的端到端演练；质量与财务为 C。
6. 仅在前置门通过后运行受控试点；监控质量失效/投诉、退换、交付、完整贡献、现金占用及顾客对可靠性的信任。指标数值阈值必须在看结果前批准。
7. 每个 Gate 单独复盘并记录继续/调整/停止；知识状态保持“待验证假设”。后来的结果只能回测决策质量，不能证明 2011 的选择必然正确。

## 草案前暴露审计

### T0 输入文件

- **评分答案泄露：未发现。** 文件只给事实、证据局限、待决策问题与一般性“不足时仍构造选项”要求，没有列出应命中的八类缺口、指定四个选项或评分禁项。
- **后见信息泄露：未发现决策结果泄露。** 它说明资料是 2013/2018/2019 的回顾并降低可信度，但没有提供 2011 之后的产品、收入、排行、研发、渠道扩张或结果。这些日期本身是证据来源属性，不是成功结果。

### Skill 正常必读文件

- **评分答案泄露：仍存在。** `chapters/ch20-global-markets.md` 的 Worked Example 直接使用“2011 年的安克冻结测试”，并列出市场规模、细分、安全/认证、完整经济性、竞争、品牌可信、履约、团队能力，以及“美国、其他市场、暂缓、小规模验证”。这些内容与本场景评分结构高度同构；只要按跨境路由正常读取 CH20，就不可能是真盲测。
- **后见信息泄露：仍存在。** `chapters/ch10-brands.md` 的 Worked Example 写到安克早期被后来回顾为“渠道品牌”，并提及产品研发、跨品类信任、溢价和新品带动力多年后的演进。虽无具体后期收入/产品名，仍是 T0 不应知道的后来解释。响应草案没有使用这些信息，但读取阶段已被污染。
- **结论**：T0 文件拆分修复有效，但端到端盲测尚未修复。需要将安克特定 Worked Example 从运行时核心章节移至 evaluator-only 或一般化为不具名示例，并清除/隔离 CH10 的安克后见段落，之后由未见过旧断言的新评测者重跑。

### 回归判定

- **顾问响应：通过。** 对 evaluator 的所有“首轮必须观察”和失败条件逐项通过。
- **T0 输入隔离：通过。** `t0-input.md` 未泄露评分答案，也未泄露后期结果。
- **端到端严格盲测：失败。** CH20 仍直接给出本场景的缺口与选项答案，CH10 仍暴露安克后来品牌/研发演进。由于这两份文件属于运行 Skill 时合理加载的必要章节，测试不能依靠“评测者不要读取”规避。
- **发布前修复条件**：把 CH20 的安克专用 Worked Example 改为不具名、不同表面情境且不复述评分清单的全球进入示例；把 CH10 的安克后见段落移出运行时核心，或改为无真实品牌、无后来阶段信息的一般化示例；随后由未参加旧版评测的新 Agent 只用 `scenario_prompt.py`、T0 和必要核心文件重跑。
