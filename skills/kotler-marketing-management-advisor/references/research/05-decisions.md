# 05｜营销决策记录与案例校验

> 调研角色：nuwa-skill Phase 1 / Agent 5（决策记录与行动）
> 调研日期：2026-09-07
> 访问日期：2026-09-07
> 任务边界：A 部分只从用户提供的《营销管理》第 16 版中提取“如何做营销决策”的案例机制；B 部分重建安克创新早期进入美国市场的历史决策，用于后续验收。安克做法属于外部事实校验，**不是**《营销管理》的核心方法。

## 0. 结论先行

1. 原书案例最有价值的部分不是“成功公司做了什么”，而是它们怎样把**顾客证据、目标市场、价值主张、市场供应品、组织能力与控制反馈**接成一条决策链。
2. 案例不能证明因果，也不能直接复制。每张案例卡必须同时写“可迁移条件”和“不可迁移条件”；否则案例只能激发模仿，不能改善决策。
3. 安克 2011 年美国市场起步可以较高置信度还原为：发现替换笔记本电池的价格—品质空档，以 Amazon 直达美国消费者，以自有品牌承接信誉，以中国供应链兑现中间价位的较高品质，再根据反馈扩展到移动充电与自研。这个叙述主要来自创始人多年后的回顾，不能伪装成 2011 年形成的完整书面战略。
4. 后来结果验证了这条路径在安克当时有效，但不能证明“Amazon + 中间价位 + 中国供应链”对今天所有跨境品牌都有效。平台竞争、合规、流量成本、品类风险、品牌认知和组织能力已经不同。
5. 后续验收应把 2011 年之后的信息隐藏起来，让 Skill 先识别资料缺口，再使用《营销管理》第 16 版的框架生成选项。若直接复述安克后来路径，应判定为事后偏差。

## 1. 证据纪律与标签

### 1.1 标签定义

- **【原书案例】**：用户提供的中文版 EPUB 在章末“营销焦点”中明确陈述的背景、行动或结果；只代表原书如何呈现案例。
- **【可归因行动】**：有可靠材料支持“企业做了这件事”，但不声称该行动单独造成结果。
- **【后来回顾】**：当事人或公司在多年后对早期经历、动机和数字的回忆；可揭示决策逻辑，但受选择性记忆与成功者偏差影响。
- **【近同期记录】**：接近事件发生时形成的报道或文件；仍需考虑采访、编辑和数据口径。
- **【你的推断】**：本调研基于证据重建的机制、可迁移条件或决策含义，不冒充作者或当事人原话。
- **【信息缺口】**：现有证据不能回答，或不同材料之间尚未调和的问题。

### 1.2 案例使用规则

每次引用案例，至少保留七栏：

1. 决策背景；
2. 当时可用信息；
3. 选择／行动；
4. 作用机制；
5. 书中或后来记录的结果；
6. 可迁移条件；
7. 不可迁移条件。

结果栏不得反向改写背景栏。案例中的“结果很好”不能变成“当时信息已经足够”；行动与结果相邻出现也不能自动升级为因果证明。

### 1.3 原书定位规则

- 原书引用采用 `MM16.CH<章号>.case-<英文短名>`。
- EPUB 没有稳定纸质页码，使用 HTML 文件和锚点定位；不得伪造页码。
- 正式公开 Skill 不包含连续原文。必要短摘录只能在用户绑定其合法本地副本后显示。
- 原书案例是教材编纂后的教学材料，不等同于企业同期档案；其可信度为“对原书陈述高，对单一行动的因果归因中等或偏低”。

## 4. 十一张决策卡

### 4.1 乐高：从复杂化失控回到研究驱动的创新

| 字段 | 记录 |
|---|---|
| 决策背景 | 【原书案例】出生率下降、儿童转向即时满足；乐高又扩展到不熟悉的主题公园并不断增加复杂套装，生产和库存复杂度上升，1998 年首次亏损，到 2003 年接近破产。 |
| 当时可用信息 | 【原书案例】零售商存在大量未售库存；产品复杂度没有带来相称销售增长；核心积木仍有强认知资产。 |
| 选择／行动 | 【原书案例】2004 年新 CEO 先改善流程、成本与现金流，再强化市场和消费者研究；研究女孩的建造与角色扮演偏好，开发 Friends 系列；设 Future Lab，以多学科团队原型化并筛选可行创意。 |
| 作用机制 | 【你的推断】先恢复公司价值与执行能力，再把用户行为证据变成产品定义；原型筛选降低大规模上市前的不确定性；组合复杂度受生产和库存约束。 |
| 结果 | 【原书案例】Friends 在多个国家受到欢迎；研究驱动转型减少生产复杂度并促进新品成功；2017 年乐高超过美泰成为最大玩具制造商。案例同时提醒实体玩具使用时长继续下降。 |
| 可迁移条件 | 企业拥有可观察的顾客行为、可做原型或小规模测试、能把调研结果传递给产品与供应链，并愿意先处理现金流和复杂度。 |
| 不可迁移条件 | 不能把“女孩喜欢角色扮演”等历史细分结论当成今天的普遍事实；不能认为成立实验室本身会带来创新；强 IP 与积木系统资产难以复制。 |
| 决策启示 | 研究不是装饰。若调研结果不能改变产品范围、资源分配或停止规则，它就没有进入决策。 |

### 4.2 欧莱雅：以细分角色管理多品牌，而不是让品牌互相蚕食

| 字段 | 记录 |
|---|---|
| 决策背景 | 【原书案例】欧莱雅从法国企业扩展为全球美妆集团，需要覆盖大众、奢侈、专业和活性化妆品等不同价值层级与渠道。 |
| 当时可用信息 | 【原书案例】各地区在文化、气候、生理与美容习惯上不同；竞争者曾忽视碎片化且易被误解的少数族裔护发市场。 |
| 选择／行动 | 【原书案例】剥离弱品牌、投资创新、收购具有民族特色的品牌；把组合分成四个部门，每个品牌服务精确细分并尽量少重合；在六个区域设研究中心做本地研究。 |
| 作用机制 | 【你的推断】组合层先定义细分角色，再让品牌、产品、价格、渠道和信息随角色分化；本地研究避免把全球规模误当成需求同质。 |
| 结果 | 【原书案例】SoftSheenCarson 成为少数族裔护发领域领导者；日本开发的 Wondercurl 三个月内成为当地畅销睫毛膏。 |
| 可迁移条件 | 品牌角色可被清晰区分；公司能承担多品牌管理成本；细分规模、可识别性、可触达性和盈利性有证据；当地研究能影响产品。 |
| 不可迁移条件 | 不能把多品牌当作自然增长路径；资源有限企业可能因品牌重复、渠道冲突和认知稀释而失控；案例结果不能证明收购优于内生开发。 |
| 决策启示 | 产品组合表要同时写“服务谁”和“为何不与现有品牌重合”，而不是只列 SKU 或价格带。 |

### 4.3 大通蓝宝石：让细分证据驱动完整供应品，而不只做促销

| 字段 | 记录 |
|---|---|
| 决策背景 | 【原书案例】大通希望强化信用卡业务；高端市场由美国运通占据，且千禧一代对负债谨慎、又看重旅行体验与奖励。 |
| 当时可用信息 | 【原书案例】2006 年研究显示，富裕顾客约占持卡人 15%，却贡献超过一半信用卡支出；进一步研究识别出收入、年龄、旅行／餐饮偏好和“刷客”风险。 |
| 选择／行动 | 【原书案例】先推出面向富裕者的 Sapphire，再推出有年费与更高旅行权益的 Preferred；2016 年以 Reserve 面向较年轻的富裕旅行者，联动金属卡、权益、积分、服务与社交影响者。 |
| 作用机制 | 【你的推断】不是靠单一高额奖励，而是把身份信号、使用场景、服务体验、价格和沟通统一到同一目标群体；续订率用于检验长期价值而非只看开户量。 |
| 结果 | 【原书案例】Reserve 上线两周即完成获客目标，早期奖励成本高；一年后续订率接近 90%，书中据此认为“刷客”问题得到缓解。 |
| 可迁移条件 | 企业能估算细分的货币与战略价值、拥有留存数据、产品权益可被持续交付、获客补贴的回收周期可测。 |
| 不可迁移条件 | 不能仅凭高奖励复制；信用卡监管、网络效应、数据规模和高价值客户经济性具有行业特殊性；高续订不自动证明终身盈利。 |
| 决策启示 | 目标市场选择应同时回答“规模多大、价值多高、我们凭什么赢、获客成本何时回收”。 |

### 4.4 凌仕与多芬：精准定位与品牌组合价值冲突

| 字段 | 记录 |
|---|---|
| 决策背景 | 【原书案例】联合利华用凌仕服务年轻男性，用多芬服务女性；两个品牌在同一母公司下采取截然不同的人群与意义定位。 |
| 当时可用信息 | 【原书案例】凌仕对男性细分后选中“缺乏安全感的新手”；多芬的研究显示女性对自我美感评价偏低；社会对男性气质和女性形象的讨论发生变化。 |
| 选择／行动 | 【原书案例】凌仕以幽默、性吸引和男性相关媒介触达，后来转向反刻板印象；多芬以“真美”持续传播多元身体形象，并配套社会项目。 |
| 作用机制 | 【你的推断】强定位来自具体受众、焦虑／愿望和情境的一致；但组合层可能出现价值观不一致，削弱母品牌可信度，必须显式治理。 |
| 结果 | 【原书案例】两者都获得高讨论度与业务成功；多芬在 15 年间销售额从约 25 亿美元升至 60 亿美元。原书本身把两品牌潜在冲突列为讨论题，而非给出简单答案。 |
| 可迁移条件 | 有足够细分研究；品牌间区隔清晰；组织能长期维持一致表达，并监测社会文化变化和组合外溢。 |
| 不可迁移条件 | 历史广告中的性别刻板印象不可照搬；争议声量不等于品牌资产；一个品牌的成功不能抵消另一品牌造成的信任风险。 |
| 决策启示 | 定位评审除“对目标顾客是否有效”外，还要增加“与企业其他品牌及公开价值观是否冲突”。 |

### 4.5 瓦尔比派克：把低价、设计、风险逆转与渠道重构成一个价值主张

| 字段 | 记录 |
|---|---|
| 决策背景 | 【原书案例】眼镜行业上下游集中，品牌眼镜价格高且购买主要在线下完成；创始人看到线上直销机会。 |
| 当时可用信息 | 【原书案例】镜架与镜片价值链集中、授权和传统零售推高成本；顾客又需要试戴与购买安全感。 |

| 作用机制 | 【你的推断】价值主张是“设计／风格 + 可负担价格 + 低风险体验 + 社会使命”的组合；每个承诺都有价值链和渠道动作支撑。 |
| 结果 | 【原书案例】五年后估值 12 亿美元，95 美元核心价格仍保持；线上模式站稳后再补实体体验。 |

| 不可迁移条件 | 高退货、强监管、无法远程评估适配性或售后成本极高的品类未必成立；案例不能证明 DTC 永久优于第三方渠道。 |
| 决策启示 | “低价”若没有成本结构、质量证据与风险逆转设计，只是促销，不是可持续定位。 |

### 4.7 优步：动态定价是供需机制，也是公平与监管决策

| 字段 | 记录 |
|---|---|
| 决策背景 | 【原书案例】传统出租车在高峰或恶劣天气供给不足；平台同时需要吸引乘客与司机。 |
| 当时可用信息 | 【原书案例】时间、距离、地点需求和司机供给可实时观察；更高价格可能吸引司机，但乘客会感知不公平。 |
| 选择／行动 | 【原书案例】从高管豪华车服务扩展到较便宜的 uberX 和拼车；高需求时采用峰时溢价，曾高达正常车费的多倍。 |
| 作用机制 | 【你的推断】价格既调节需求，也把供给吸引到短缺区域；服务版本形成细分梯度。负面机制是参考价格被打破、灾害情境引发剥削感，并放大监管反弹。 |
| 结果 | 【原书案例】便利性与价格结构推动全球扩张；峰时账单引发社交媒体抗议，多个市场出现合法性和监管冲突。 |

| 决策启示 | 定价板必须同时展示顾客价值、公司收益、合作者激励、参考价格、公平感和监管后果。 |

### 4.8 飒拉：把顾客反馈变成供应链速度，而不是只做趋势报告

| 字段 | 记录 |
|---|---|
| 决策背景 | 【原书案例】时尚需求易逝、预测误差高，传统行业从设计到上架可达数月并产生高库存风险。 |
| 当时可用信息 | 【原书案例】门店意见、穿着观察、潮流场所、博主和跨地区趋势可持续回流；基础款与短周期潮流款的需求性质不同。 |
| 选择／行动 | 【原书案例】潮流款内部快速生产、小批量上架、3—4 周轮换；基础款外包；未达预期时迅速停产；对地区尺码、服装类型和气候适配。 |
| 作用机制 | 【你的推断】高频小批量形成真实需求实验，稀缺促进到店并降低失败库存；纵向整合和信息流把洞察变成 15 天左右的响应。 |
| 结果 | 【原书案例】每年推出大量款式，顾客到店频率显著高于一般服装店；可调整 40%—50% 订单以降低过剩。 |
| 可迁移条件 | 产品周期短、可小批量补货、反馈快速可靠、供应链可重排、顾客愿意接受高频变化。 |
| 不可迁移条件 | 长研发／认证周期、规模经济极强或安全关键产品不适合照搬；快时尚的环境和劳工外部性不能被库存效率遮蔽。 |
| 决策启示 | “顾客洞察”只有改变补货、停产、设计或渠道动作，才形成控制循环。 |

### 4.9 博派斯：渠道伙伴经济性是营销执行的一部分

| 字段 | 记录 |
|---|---|
| 决策背景 | 【原书案例】博派斯品牌认知弱、产品创新不足、财务表现差，加盟商长期不满，与管理层冲突。 |
| 当时可用信息 | 【原书案例】加盟商关心门店盈利；全国广告缺失；品牌的路易斯安那来源具备差异化；既有选址偏见限制门店成功。 |
| 选择／行动 | 【原书案例】管理层与加盟商共同起草计划；双方增加全国广告投入；重建路易斯安那定位、门店与新品；投资选址数据分析，把门店盈利纳入改进。 |
| 作用机制 | 【你的推断】公司与合作者重新分担投入和收益，3V 中的“合作者价值”被显式纳入；统一品牌资产与本地门店经济性互相支持。 |
| 结果 | 【原书案例】销售增长、重新盈利、加盟商满意度提高，新店数量增长并扩展到全球。 |

| 不可迁移条件 | 不能把提高渠道费用视为通用答案；权力结构、合同、单位经济性和地区差异若不透明，协商可能只转移成本。 |
| 决策启示 | 渠道冲突诊断先问“谁创造什么价值、谁承担什么成本、谁获得什么回报”，再谈控制权。 |

### 4.10 美捷步：顾客服务定位必须写进组织系统

| 字段 | 记录 |
|---|---|
| 决策背景 | 【原书案例】线上鞋类购买有适配和信任障碍；许多零售商把客服电话视为成本中心。 |
| 当时可用信息 | 【原书案例】电话可建立人际连接；长期员工更可能理解文化；出色服务可能提高顾客终身价值，而非只增加当期成本。 |
| 选择／行动 | 【原书案例】醒目展示客服电话；客服不外包；总部与呼叫中心整合；招聘把文化契合作为重要标准；培训、授权员工自行创造惊喜；免费快速配送和 365 天退货。 |
| 作用机制 | 【你的推断】服务承诺被转化为人员选择、能力、授权、政策和成本结构；内部营销使前线行为与外部定位一致。 |

| 不可迁移条件 | 高退货政策、重人工服务和文化筛选并非所有品类都盈利；“文化契合”可能产生同质化与歧视风险。 |
| 决策启示 | 若定位声称“卓越服务”，执行计划必须列招聘、培训、授权、服务政策和留存指标，不能只写传播口号。 |

### 4.11 宜家：固定价值逻辑，适配本地障碍

|---|---|
| 决策背景 | 【原书案例】宜家以低价、设计和自组装在欧洲成功，但进入中国等市场时，相同价值主张和门店方式并不天然成立。 |

| 可迁移条件 | 企业能辨认哪些能力产生全球规模优势，哪些顾客障碍由当地文化、基础设施、购买力和渠道造成。 |
| 不可迁移条件 | 宜家的规模采购、供应链和门店资本不可复制；“年轻中产”不是所有中国／海外市场的永恒目标群体。 |
| 决策启示 | 国际化方案要逐项标记“全球固定／本地适配／待测试”，并说明对品牌一致性和成本的影响。 |

## 8. T0 决策板：站在 2011 年，当时真正知道什么

### 8.1 相对可靠的决策输入

| 维度 | T0 可用信息 | 证据性质 |
|---|---|---|
| 顾客问题 | 更换老化笔记本电池时，在“原厂昂贵”和“第三方评价差”之间缺少令人放心的选择。 | 【后来回顾】S4、S7；合理但缺少同期样本与市场规模 |
| 目标市场 | 创始团队在美国生活／工作，对欧美用户和平台更熟悉；美国消费者可经 Amazon 直接触达。 | 【后来回顾】S4；“熟悉”没有量化 |
| 竞争／替代 | 原厂电池约 70—80 美元、平台低价产品约十几美元；评价存在差距。 | 【后来回顾】S4；无历史页面快照，必须作为待核假设 |

| 价值主张雏形 | 自有品牌、比原厂便宜、比无品牌产品可靠，直接面向美国终端消费者。 | 【可归因行动＋后来回顾】S4、S7、S8 |

### 8.2 2011 年不应假装已经知道的事

- 【信息缺口】美国替换笔记本电池市场的总量、增长率、利润池与细分规模；现有材料只有平台观察和创始人个人问题。
- 【信息缺口】产品失效率、安全、召回、保险和责任成本；电池是安全敏感品类，星级不能替代技术与合规验证。
- 【信息缺口】精确单位经济性：采购、测试、关税、头程、仓储、退换、Amazon 费用、广告、售后与坏账。
- 【信息缺口】竞品真实销量、评论真实性、原厂反应、平台自营／规则变化和知识产权风险。
- 【信息缺口】目标顾客究竟是按设备型号、价格敏感度、紧急程度、技术能力还是信任需求细分。
- 【信息缺口】自有品牌名称在美国的商标、搜索认知、可信理由和品牌资产建设计划。
- 【信息缺口】为何先美国而非欧洲／日本的书面国别比较；“更熟悉美国”是重要公司适配因素，但不能替代 CH20 的国家吸引力／风险评估。
- 【信息缺口】首批产品的正式质量测试报告、样本量、退货率及售后设计。

### 8.3 可确认的实际选择

1. **【可归因行动】市场顺序：**美国先行，并以 Amazon 作为主要直接触达入口。
2. **【可归因行动】切入品类：**替换笔记本电池／充电配件，而不是整机等高资本、强品牌品类。
3. **【可归因行动】价值位置：**自有品牌承接信誉，位于高价原厂和低质白牌之间，以中间价位提供更可靠品质。
4. **【可归因行动】价值链：**在中国寻找／测试产品，以跨境电商和美国仓储物流绕过传统多级经销。
5. **【后来回顾】验证目标：**首年销量、评价和盈利后，把这套选择扩展到移动充电问题，并开始自建研发能力。

### 8.4 机制重建

以下均为【你的推断】，不是安克或科特勒原话：

```text
平台可见的价格—评价空档
  ↓
选择“可负担但可信”的价值位置
  ↓
自有品牌承接信誉 + 中国供应链兑现品质／成本
  ↓
Amazon 直达消费者，降低初始分销门槛
  ↓
评价、退货与销量形成快速市场反馈
  ↓
把早期交易学习投入产品改良和研发
  ↓
从渠道可得性逐步积累产品与品牌资产
```

这条链上任何一环都可能失效。平台触达不能弥补产品安全；中间价位不能替代可信差异；好评不能自动等于长期品牌；供应链低成本也不能替代研发和质量控制。

## 9. T1／T2：后来结果如何验证，又不能证明什么

### 9.1 能支持的判断

- 【后来回顾】S7 中，阳萌称首年售出约 50 万件、平均评分约 4.3／5 并实现盈利。若口径准确，至少说明早期供应品通过了初步市场与单位经济性验证。
- 【后来回顾】S4 称 2011 年销售额约 1900 万元、2018 年约 52 亿元；S3 对 2018 年营业收入披露为 52.322 亿元，量级相符，但 2011 年数字没有审计材料交叉核验。
- 【可归因行动】S3 表明 2014 年以后产品线逐步扩展，2017—2019 年北美仍贡献约一半主营收入，Amazon 仍是主要渠道；这支持“美国＋Amazon”确为核心起点并形成规模。
- 【可归因行动】S3 与 S5 支持公司从渠道销售逐步增加研发、品牌、产品线和线下渠道能力，而不是永远停留在选品贸易。
- 【后来结果】Amazon 占比和线上 B2C 占比在 2017—2019 年下降，说明公司后来主动增加其他平台与线下渠道；同时占比仍高，平台依赖没有消失。

### 9.2 不能支持的判断

- 不能证明当时做过完整、严谨的 STP 或 G-STIC 书面流程；现有证据更像创业者观察、快速选择与迭代。
- 不能证明“中间价格带”是成功的唯一原因。渠道红利、品类时机、创始团队背景、供应链、评价机制、执行速度与后续研发可能共同作用。
- 不能证明所有自有商标从第一天就是强品牌。**拥有品牌名称**、**渠道内有信誉**和**拥有跨品类品牌资产**是三个不同阶段。
- 不能证明先单一平台再多渠道始终最优。安克后来降低 Amazon 占比本身反映了集中风险与增长需要。
- 不能把 2017—2019 年的组织、研发、专利、线下渠道和品牌能力倒灌到 2011 年团队。
- 不能把 Amazon 评论视为无偏的消费者研究总体；它只覆盖平台购买者、已售产品和愿意评论的人。

## 11. 安克历史案例的矛盾与未决问题

### 11.1 可解释但必须保留的矛盾

1. **成立时间／起点口径不同。** S4 称阳萌 2011 年 7 月离职并与同事在长沙创办公司；S8 近同期报道的 OCR 显示为 2011 年秋；S3 的境内法人登记日为 2011-12-06；Fantasia 又早在 2009 年设立。它们可能分别指离职与筹备、实际运营、境内法人登记、美国销售实体，不能压成一个“唯一成立日”。
2. **“从第一天做品牌”与“渠道品牌阶段”。** S8 记录早期即注册自有品牌；S4／S5 又称 2011—2014 为渠道品牌或以选品销售为主。最合理解释是：早期拥有自有商标和质量承诺，但跨品类的消费者认知、溢价和新品带动力是在多年后形成。
3. **研发时间口径。** S7 说 2012 年 5 月设首个深圳研发中心；S5 说 2012 年开研发办公室、到 2014 年才具备独立研发能力；S3 以 2014 年无线音频新品作为主营业务演进节点。地点存在即可验证，但“具备自研能力”是渐进而非单点事件。
4. **早期价格数字来自回忆。** S4 给出原厂 70—80 美元、白牌十几美元、安克目标 30—40 美元；S8 的扫描数字有乱码。价格带方向有多源支持，但精确数字不应当作无误的 2011 年市场快照。

### 11.2 信息缺口

- 未取得 2011 年 Amazon 商品页面、竞品榜单和评论原始快照。
- 未取得第一批产品的型号清单、测试标准、失效率、退货率、毛利和营销费用。
- 未取得 2011 年的内部商业计划、国别选择备忘录、品牌定位文档或会议记录。
- 未能独立审计创始人口述的首年 50 万件、4.3 星和 1900 万元销售额。
- 对早期美国仓配合作方、消费者服务标准、合规认证与产品责任安排的资料不完整。
- 缺少早期失败 SKU、被否决选项和竞争反应，公开叙述明显偏向成功路径。
- 缺少当时团队对欧洲、日本等备选市场的同口径比较，因此无法判断美国是否是“全局最优”还是“创始人最匹配的可行起点”。

## 12. 后续验收用例设计

### 12.1 主测试：冻结在 2011 年

给待测 Skill 只提供以下信息：

> 一支中国创业团队有美国生活和技术背景，观察到 Amazon 的替换笔记本电池市场存在高价原厂与低价低评分第三方产品两端；团队能接触中国供应链，希望用自有品牌进入美国，但不熟悉报关、平台运营和本地售后。

合格输出必须：

1. 先指出市场规模、顾客细分、产品安全／认证、单位经济性、竞争、品牌可信理由、履约和团队能力等关键缺口及其重要性；
2. 用 CH20 判断“是否进入、进入哪里、如何进入”，而不是默认 Amazon；
3. 用 CH05／06／07 把平台现象转成待验证的目标市场与价值主张；
4. 用 CH08／10／11／15 检查产品、品牌、价格、渠道与履约的一致性；
5. 陈列至少两个可行选项和“不进入／推迟进入”的基准选项；
6. 给出条件式倾向，但保留用户最终决定；
7. 设计小规模验证、领先指标、停止条件和复盘点；
8. 不提及 PowerIQ、后来收入、畅销榜、线下渠道或品牌成功等 T1／T2 信息。

### 12.2 五个关键变体

| 变体 | 只改变什么 | 要检验的能力 |
|---|---|---|
| V1 安全证据不足 | 供应商不能提供一致的电芯追溯与失效测试 | Skill 是否设置资料闸门，而不是被价格空档诱导进入 |
| V2 单位经济性不成立 | 算入退货、保险和平台费用后中间价位亏损 | 是否重做价格／价值链，而非机械坚持 30—40 美元 |
| V3 美国并非最佳首站 | 团队更熟悉德国且已有当地服务伙伴，美国竞争更强 | 是否真正比较目标市场与公司匹配，而非崇拜案例结果 |
| V4 平台集中风险高 | Amazon 可触达但账号、政策和流量成本波动大 | 是否设计阶段性平台策略、备援渠道和依赖监控 |
| V5 品牌承诺无法兑现 | 能贴自有商标，但无法控制设计、质量和售后 | 是否区分商标、渠道信誉与品牌资产，并建议推迟品牌扩张 |

### 12.3 分阶段披露

1. 待测 Skill 完成 T0 决策板后，披露“首年 50 万件、约 4.3 星、盈利”的 T1 反馈，要求更新而非自我庆祝。
2. 再披露“2012 研发中心、2014 逐步自研”，观察是否把新能力当作新决策输入。
3. 最后披露 2017—2019 审计收入、北美占比、Amazon 占比和产品排名，要求区分结果、机制和残余风险。
4. 若 Skill 以后来成功证明早期所有假设正确，或忽略平台依赖、质量与品牌阶段差异，应判不通过。
