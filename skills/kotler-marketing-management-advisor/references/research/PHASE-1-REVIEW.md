## 2. 已达到的共同结论

### 2.1 核心框架

第16版不是“STP + 4P”的简单工具包，而是一套价值驱动的营销管理系统：

```text
Goal 目标
  ↓
Strategy 战略：5C 定义市场情境 → 目标市场 → 3V 价值主张
  ↓
Tactics 战术：7T 设计产品、服务、品牌、价格、激励、沟通、分销
  ↓
Implementation 实施：资源、流程、人员、组织协同
  ↓
Control 控制：指标、偏差诊断、学习、调整
```

21 章再把这条主线展开到调研、细分与定位、产品/服务/品牌/价格、沟通/数字/销售、渠道/零售、竞争增长/创新/忠诚/全球化/责任。

### 2.2 顾问行为

公开材料中最稳定的“科特勒式”不是语气模仿，而是：

1. 先校准用户真正要做的决策、分析单位和层级；
2. 把局部战术问题上溯到目标、目标市场与价值主张；
3. 关键上下文不足时说明缺什么、为什么重要、会阻塞什么结论；
4. 用案例解释机制，但不把成功案例当因果证明；
5. 明确区分事实、假设与推断，以情景和触发信号处理不可量化的不确定性；
6. 陈列选项和条件式倾向，把最终选择留给用户；
7. 对欺骗、操纵、腐败、隐私滥用和掩盖伤害设置边界。

### 2.3 案例与行动

原书案例的可迁移价值集中于“证据—选择—供应品—能力—反馈”闭环，而非复制名企动作。安克历史校验进一步显示：自有商标、渠道信誉、产品能力和跨品类品牌资产是不同阶段；后来成功不能倒灌成 2011 年已经知道的事实。

## 3. 必须保留、不能强行统一的张力

| 张力 | 为什么不能抹平 | 构建时的处理 |
|---|---|---|
| “科特勒式”角色 vs 三人共同作者 | 第16版是 Kotler/Keller/Chernev 合著，部分核心图式明确承接 Chernev | 常驻 AI 模拟声明；模型级精确归属 |
| 指定第16版 vs 截至2026已有第17版 | 用户选择的是稳定基准，当前版本事实却已变化 | 核心版本锁定 `16e`；17版只做边界提示或经同意进入扩展层 |
| 系统完整性 vs 一线可执行性 | 教材完整但中小企业资源和时间有限 | 主控路由按需披露；一次只聚焦 1—3 个战略/阻塞性瓶颈 |
| 顾客中心 vs 多利益相关者与社会责任 | 顾客价值不是忽略公司、合作者、员工与社会成本 | 重大决策同时检查 3V 与第21章责任边界 |
| 稳定战略逻辑 vs 快速变化的工具/平台 | 技术改变触点和事实，不自动替代战略 | 外部事实可更新；外部方法必须授权并显式标记 |
| 全球通用概念 vs 本地市场差异 | 跨国应用依赖文化、购买力、渠道、监管和企业匹配 | 逐项标记全球固定/本地适配/待验证，而非整体二选一 |
| 计划与控制 vs 创业探索和涌现 | 初创企业缺完整数据，仍需行动学习 | 用最小信息、可逆实验、停止条件和复盘补足，而非伪造确定性 |
| 科学测量 vs 无法可靠量化的不确定性 | 有些概率没有可靠基线 | 可量化处量化；不可量化处用情景、触发信号和可逆行动 |

## 4. 已知缺口

1. **英文第16版没有全文逐段校对。** 目前只用官方英文目录与书目校验术语；中文 EPUB 仍是唯一内容主源。
2. **缺少大规模原始课堂与真实咨询记录。** 公开访谈足以提炼对话动作，但不能声称复制 Philip Kotler 私下咨询的完整思维。
3. **没有三位作者逐章分工表。** 除原书明确标注的模型来源外，不推断单章作者。
4. **直接针对第16版的独立学术评论较少。** 很多批评针对营销管理传统或旧版；只能作为边界，不是对第16版逐条证伪。
5. **没有证据证明“使用该教材/Skill 会因果性提升企业绩效”。** 验收应测决策质量、证据纪律与执行闭环，不能承诺商业结果。
6. **书中案例具有年代性。** 案例只解释机制；当前市场、顾客、竞争和规则必须另查并带日期。
7. **安克 T0 资料不完整。** 缺 2011 Amazon 快照、内部计划、首批 SKU 单位经济性、质量档案、失败选项和同口径国别比较。
8. **尚无具体企业运行数据。** 这是设计上的运行时输入，而非研究缺陷；Skill 必须通过最小资料闸门补齐，不能预置虚构企业事实。

## 5. Phase 2 的硬约束

若用户批准进入下一阶段，必须遵守：

1. 只从第16版提炼核心心智模型、启发式与工作流；外部研究只影响表达、边界和验收。
2. 先构建全书知识宪法与路由，再深化用户洞察、目标市场、品牌定位、产品组合、定价、渠道、团队管理七个模块。
3. 每个工作流统一包含资料闸门、诊断、质疑、决策板、用户选择、行动计划、指标、复盘和知识晋级。
4. 每条核心规则附章号、概念、推理链；本地书可用时才显示必要短摘录。
5. 明确“个人学习档案”“企业事实库”“案例档案”“已批准知识”四种状态，权限与晋级分离。
6. 验收必须包含：完整 Mock 品牌、5 个关键变体、安克 2011 冻结测试，以及错误来源混合/缺资料仍下结论/虚构本人身份等负例。

## 6. 阶段判定

**建议：有条件进入 Phase 2。**

理由：六个研究维度均完成，核心框架、表达规则、边界、归属和历史验收已形成交叉证据；未决缺口已经能够通过显式限制管理，不阻塞模型提炼。

进入 Phase 2 前需要用户确认的不是再次选择需求，而是确认以下研究结论作为构建基线：

- 第16版按三位作者共同成果归属；“科特勒式”是透明的 AI 顾问角色。
- 第17版和作者后续方法不进入核心。
- 公开表达证据不能被宣称为私人咨询复刻。
- 案例用于解释机制与验收，不作为保证结果的处方。
