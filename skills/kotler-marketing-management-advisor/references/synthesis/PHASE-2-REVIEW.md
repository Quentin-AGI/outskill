## 2. 六个模型为何不是工具堆砌

| 模型 | 它回答的根问题 | 与其他模型的边界 |
|---|---|---|
| M1 市场价值系统观 | 营销究竟是什么、是谁的工作 | 定义系统，不负责具体排序 |
| M2 需求定义市场的 5C 镜片 | 市场边界和事实从哪里开始 | 负责观察情境，不替代选择 |
| M3 G-STIC 因果栈 | 决策按什么层级、顺序与反馈运行 | 负责过程，不直接判定价值可持续 |
| M4 3V 可持续交换 | 方案对关键参与方是否能长期成立 | 负责价值生存性，不设计具体战术 |
| M5 一致性市场供应品 | 战略如何由 7T 变成市场现实 | 负责横向一致，不替代目标选择 |
| M6 双时间尺度市场资产循环 | 如何平衡当期绩效与长期顾客/品牌/能力 | 负责跨期控制与增长 |

STP、共同点/差异点、品牌价值链、定价六步、IMC、渠道治理、门径管理等仍保留精确名称，但进入专业工具层，不与六个总模型并列。

## 3. 十条启发式

1. 先命名决策，再讨论答案；
2. 没有成功基准，就不比较方案；
3. 关键证据缺失，先开资料闸门；
4. 战术问题先向上追一层；
5. 市场从需要开始，不从平台类目开始；
6. 目标市场必须同时写服务谁与不服务谁；
7. 差异化必须通过合意、可兑现、可区分三道门；
8. 重大方案必须通过 3V 与责任否决门；
9. 优先修复战略影响大且阻塞其他模块的 1—3 个瓶颈；
10. 提出行动时同时定义学习、阈值、停止与复盘规则。

## 4. 七大工作流共同结构

每个模块都已经按同一契约设计：

```text
适用触发
→ 最小资料闸门（致命/重要/可选）
→ 书中框架诊断
→ 顾问式质疑与反证
→ 四级成熟度
→ 2—4 个选项的营销决策板
→ 用户选择
→ 行动/RACI
→ 指标、阈值和复盘
→ 案例沉淀与负责人批准晋级
```

每个工作流已明确主章节、交叉章节、模板清单、指标和反模式。W6 特别把“价值交付渠道”和“价值沟通/投放”分开，以免平台流量替代渠道战略。

## 5. 三层式操作系统

- **L1 稳定核心**：第16版知识宪法、六模型、十启发式、证据/身份/版权/隐私边界。
- **L2 专业工作流**：七个可按需调用的业务流程；用户不必先完成全公司体检。
- **L3 企业私有工作区**：企业事实、个人私有学习档案、案例、经验、已批准知识和扩展包。

采用渐进式初始化：零配置 → 单案例 → 企业配置 → 组织学习；本地 EPUB 是独立可选增强层。

## 6. 相对 Phase 1 的关键合成判断

1. **不把“科特勒式”做成人物口吻包。** 角色辨识度主要来自问题校准、系统层级、证据纪律和条件式判断。
2. **不把 STP + 4P 当全部主线。** 第16版的顶层主板锁定为 G-STIC + 5C + 3V + 7T。
3. **不让全面体检成为使用门槛。** 直接问题进入相关模块，仅补最小全局上下文；多模块反复失效时再建议体检。
4. **不把标准记录做成僵硬长表。** 使用固定外壳 + 条件模块 + 20% 自由扩展区。
5. **不让复盘经验自动污染企业知识。** 经验沿状态机晋级，只有营销负责人能批准为正式品牌知识。
6. **不把当前市场事实或平台规则升级成方法。** 当前事实可以自动查询并标来源；外部方法必须说明边界并征得同意。

## 7. Phase 3 构建边界

用户确认后才生成最终可运行包，包括：主控 Skill、按章知识、七个工作流、可填写模板、私有工作区协议、Mock 教程、测试集和本地 EPUB 增强工具。

Phase 3 必须保持：

- 核心方法只来自第16版；
- 三位作者与模型来源准确归属；
- 公开包不含 EPUB/连续原文/企业数据；
- 第一人称伴随 AI 模拟声明；
- 关键事实带来源类型、日期和可信度；
- 没有关键资料时阻止确定性结论；
- 所有建议能落到决策、行动、指标与复盘。

## 8. 阶段判定

**建议进入 Phase 3。**

六个模型通过三重检查且彼此分工清楚；十条启发式可被新情境触发；七个工作流覆盖首批用户最重要的决策域；关键张力、归属、隐私、版权和能力边界已经固化。

进入 Phase 3 前需要用户确认：是否认可“6 个模型 + 10 条启发式 + 7 个工作流 + 三层式操作系统”作为最终 Skill 的认知架构。
