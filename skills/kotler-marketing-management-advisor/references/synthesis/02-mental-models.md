# Phase 2.1｜六个核心心智模型

> 核心来源：Kotler、Keller、Chernev 合著《营销管理》第16版。模型名称是本项目为了运行清晰度做的中文封装；其中 G-STIC、5C、3V、7T 保留原书精确名称与归属，不宣称新造理论。

## M1｜市场价值系统观（Market-Value System View）

**一句话**：不要把营销看作推广部门；把它看作企业选择价值、创造价值、沟通价值、交付价值并获取合理回报的全公司系统。

**三重验证**

- 跨域复现：Ch1–2 定义营销与全方位营销；Ch8–16 分别设计、沟通、交付价值；Ch17–21 管理增长、关系、全球化和责任。
- 生成力：面对广告、渠道或销量问题，会先追问“为谁创造了什么价值，哪一环没有成立”，而非立刻优化传播。
- 排他性：它明确反对把营销缩成 Promotion，并把内部营销、关系、绩效和责任纳入同一系统。

**运行方式**

1. 识别价值主体与分析单位：公司、业务、品牌、市场供应品或活动。
2. 沿“选择—设计—沟通—交付—获取—再投资”寻找断点。
3. 检查断点是否来自营销、产品、服务、运营、销售、财务或伙伴协同。
4. 把建议落到跨职能责任，而不是只给营销部门任务。

**证据场景**：美捷步的服务定位依赖招聘、培训、授权和退货政策；瓦尔比派克的低价依赖价值链、试戴、退货与渠道共同重构。

**局限**：系统观容易变成“什么都重要”。必须由 G-STIC 目标和瓶颈排序把范围压缩到当前最重要的 1—3 个问题。

## M2｜需求定义市场的 5C 镜片（Need-Defined Market Lens）

**一句话**：先从目标顾客的需要定义市场，再用 Customer、Company、Collaborator、Competitor、Context 建立情境；不要让现有产品、平台类目或行业名称替你定义竞争。

**三重验证**

- 跨域复现：Ch1–2 的市场价值观念与 5C；Ch3–5 的顾客/调研；Ch6 的细分；Ch17–18 的增长创新；Ch20 的国家市场选择。
- 生成力：会寻找满足同一需要的跨品类替代品，也会发现现有产品之外的市场和创新空间。
- 排他性：以顾客需要为中心的 5C 明确不同于只看同类卖家或行业五力。

**运行方式**

1. 将“我们卖什么”改写成“谁在何种情境下试图完成什么、为何现有解决方案不够好”。
2. 分别收集五类事实，标注来源、日期与可信度。
3. 把竞争者扩展为所有可替代方案，包括不购买、自行解决和跨品类方案。
4. 识别哪些 5C 变化会迫使目标市场、价值主张或战术重做。

**证据场景**：一家办公照明品牌若只把市场定义成“台灯类目”，会漏掉顾客对眼部舒适、空间适配和工作节律的需要，也会漏掉自然光、屏幕设置和不购买等替代方案。

**局限**：5C 会扩大研究范围。当前任务只收集会改变决策的最小事实，不强制先完成全公司体检。

## M3｜G-STIC 因果栈（G-STIC Causal Stack）

**一句话**：Goal → Strategy → Tactics → Implementation → Control 是有依赖关系的因果栈；下游问题可能由上游缺陷造成，控制结果必须允许回退修订。

**三重验证**

- 跨域复现：Ch2 直接定义；Ch6–7 提供战略；Ch8–16 提供战术；Ch14、18 提供执行；Ch1、2、5、19 提供控制。
- 生成力：看到投放差会依次检查投入/执行、组合、战略、目标，而不自动把责任归给素材或预算。
- 排他性：第16版把 G-STIC 作为行动计划主板，并明确战略由目标市场和价值主张构成、战术由 7T 构成。

**运行方式**

1. Goal：写明重点、量化/可观察基准、期限及非目标。
2. Strategy：确定目标市场和 3V 价值主张。
3. Tactics：设计相互一致的 7T。
4. Implementation：指定资源、开发、部署、负责人、依赖。
5. Control：预设指标、阈值、环境信号和继续/调整/停止规则。

**证据场景**：Zara 用小批量、高频反馈、快速补货与停产把控制变成下一轮产品和库存决策；乐高先修复复杂度与现金流，再让调研进入创新决策。

**局限**：顺序不是瀑布。Ch18 显示创新会迭代回退；流程应是检查点，而不是官僚关卡。

## M4｜3V 可持续交换（Three-Value Sustainable Exchange）

**一句话**：一个营销方案只有同时为 Customer、Collaborator、Company 创造卓越且可持续的价值，才是可生存的市场交换。

**三重验证**

- 跨域复现：Ch1 的关系/利益相关者；Ch2 的 3V；Ch6 的吸引力与兼容性；Ch15 的渠道伙伴；Ch19 的顾客资产；Ch21 的责任。
- 生成力：能识别“顾客喜欢但公司亏损”“公司赚钱但伙伴没动力”“短期三方获利但社会伤害不可接受”等伪成功。
- 排他性：三方价值联立比单纯“顾客第一”或“利润最大化”更具判断约束。

**运行方式**

1. 顾客价值：相对替代方案的功能、心理和货币收益—成本。
2. 合作者价值：伙伴为何参与、投入什么、承担什么风险、得到什么回报。
3. 公司价值：财务价值、战略价值、能力积累、机会成本与风险。
4. 横向加入员工、社区、环境和合法性检查；发现不可接受外部性时否决或重构。

**证据场景**：博派斯把加盟商经济性纳入共同计划；优步动态定价既可能匹配供需，也会触发公平与监管问题。

**局限**：三方价值常有冲突，没有通用权重。Skill 必须陈列取舍、受影响主体和决策权，不伪造唯一最优解。

## M5｜一致性市场供应品（Coherent Market Offering）

**一句话**：定位不是一句话，战略也不是 PPT；目标市场与价值主张必须由 Product、Service、Brand、Price、Incentives、Communication、Distribution 七个战术要素共同兑现。

**三重验证**

- 跨域复现：Ch1 的整合营销；Ch2 的 7T；Ch7 定位；Ch8–16 各战术；Ch20 全球标准化与适配。
- 生成力：任何单点建议都会被问“它与其他六项是否一致、谁来交付、是否破坏定位”。
- 排他性：第16版显式拆开服务、品牌、激励和沟通，避免 4P 中的隐藏与混淆。

**运行方式**

1. 写出目标市场、参照系、共同点、差异点和价值证明。
2. 为每个 7T 标注：如何支持定位、负责人、成本、证据、依赖。
3. 检查缺项、冲突和无法兑现的承诺。
4. 全球/多渠道场景逐项决定固定、适配或测试，不做整体二选一。

**证据场景**：大通蓝宝石把细分、金属卡、权益、年费、服务与传播对齐；瓦尔比派克把低价、设计、居家试戴和 DTC 联成一个供应品。

**局限**：一致性不等于僵化或所有触点完全相同。应稳定价值逻辑，允许不同情境下的战术适配。

## M6｜双时间尺度市场资产循环（Dual-Horizon Market Asset Loop）

**一句话**：同时管理当期绩效与顾客/品牌/能力的长期复利；短期可见回报不能自动压倒关系、忠诚、创新和品牌资产。

**三重验证**

- 跨域复现：Ch1 绩效与关系营销；Ch10 品牌资产/价值链；Ch17–18 增长与创新；Ch19 CLV/顾客资产；Ch21 长期责任。
- 生成力：面对增长会同时问获客、留存、复购、品牌心智、能力积累和残余风险，而不是只看销售或 ROAS。
- 排他性：把品牌资产与顾客资产纳入营销控制，要求短期/长期、财务/非财务指标并列。

**运行方式**

1. 将指标分为领先/滞后、短期/长期、财务/非财务四象限。
2. 识别增长动作是在消耗还是积累顾客信任、品牌含义、数据、渠道关系和组织能力。
3. 设 7 天基线、30 天验证、90 天复盘，并按真实反馈周期调整。
4. 把复盘结论沉淀为案例；只有营销负责人批准后才晋级为正式品牌知识。

**证据场景**：大通蓝宝石不能只看开户量，还看续订；美捷步把服务成本与回头客关系结合；一家平台卖家的商标、渠道信誉、可迁移顾客信任与品牌资产也应分阶段判断。

**局限**：品牌资产和长期因果难精确归因。不得用不可验证的“长期主义”逃避当期问责，也不得用短期易测指标替代长期价值。

## 六模型的运行顺序

```text
M1 我们正在管理哪条价值系统？
  → M2 市场由谁的什么需要定义，5C 事实是什么？
    → M3 当前决策位于 G/STIC 哪层，上游是否成立？
      → M4 顾客、合作者、公司价值是否同时可持续？
        → M5 目标市场/价值主张是否被一致的 7T 兑现？
          → M6 当期结果与长期市场资产如何共同受控？
```

这是一条诊断顺序，不是要求用户每次阅读六段理论。主控 Skill 只披露当前问题所需层次。
