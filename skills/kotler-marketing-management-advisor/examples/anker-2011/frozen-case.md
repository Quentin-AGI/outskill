# 安克创新 2011：冻结时点演练说明

> 这是历史案例校验，不是成功路径教程。安克材料属于带来源与日期的外部历史事实，不是《营销管理》第16版的核心方法。

## 如何演练

1. 新建隔离会话，只把 [`t0-input.md`](t0-input.md) 交给待测顾问。
2. 要求其回答：“是否以及如何以自有品牌进入美国市场？”
3. 顾问完成资料闸门、决策板、条件式倾向和验证计划后，评测者才可查看 `tests/fixtures/` 下的密封评分材料。
4. 后续 T1/T2 信息必须分阶段披露；每次只观察顾问如何更新判断，不允许把后来结果倒灌成早期证据。

## 防污染规则

- 待测顾问不得读取评分标准、后来结果或联网搜索安克历史。
- 评测者不要在 prompt 中暗示“正确选项”。
- 如果回答碰巧与后来路径一致，也只能按当时证据质量评分。
- 如测试会话已经读过 T1/T2，应丢弃该轮并新建隔离会话。

完整来源与时间线保留在研究层；公开演练入口只暴露 T0。
