# 营销决策速查

## 先判断卡在哪一层

| 现象 | 先查 | 不要先做 |
|---|---|---|
| 销量/ROAS 下滑 | Goal、目标顾客、价值主张、7T、执行依次上溯 | 直接加预算/换素材 |
| 市场很大但进不去 | 目标吸引力 × 目标兼容性 | 只看 TAM |
| 品牌“不清晰” | 参照系、共同点、差异点、可信理由 | 先改 slogan/logo |
| SKU 太多 | 真实贡献、需要覆盖、复杂度、一致性 | 只按销售额砍品 |
| 价格竞争 | 顾客价值、完整成本、替代、伙伴、品牌 | 盲目跟价 |
| 渠道依赖 | 顾客任务、3V、控制/数据、退出/备援 | 同时铺更多平台 |
| 团队协同差 | 共同 Goal、决策权、接口、指标激励 | 先招聘/重组 |

## 十条 If/Then

1. 如果说不清要决定什么，先写决策句。
2. 如果没有成功基准，不排名方案。
3. 如果缺口改变战略/安全/经济性/合法性，暂停结论。
4. 如果问题在战术层，至少检查一层上游。
5. 如果市场按产品/平台定义，改用顾客需要和 5C。
6. 如果目标是“所有人”，写明不服务谁。
7. 如果差异不被重视、不能兑现或易复制，删除。
8. 如果一方长期得不到价值，3V 不通过。
9. 如果问题很多，先修战略影响大且阻塞下游的 1—3 个。
10. 如果要行动，同时写阈值和继续/调整/停止。

## 决策输出最小集

```text
问题/Goal
→ 致命资料缺口
→ 第16版章节与概念
→ 事实/假设/可信度
→ 2—4 个选项 + 成立条件/代价
→ 条件式倾向
→ 用户选择
→ 动作/RACI/指标/阈值/复盘
```

## 证据标签

- 书中：章号/概念/必要短摘录；
- 外部：来源/日期/访问日/可信度；
- 企业：提供者/更新时间/可信度；
- 推断：依赖事实和框架；
- 假设：验证方法及受影响判断。

## 默认节奏

7 天基线 → 30 天验证 → 90 天复盘 → 季度再诊断 → 年度校准。若真实反馈周期不同，覆盖默认值。
